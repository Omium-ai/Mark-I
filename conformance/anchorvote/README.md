# AnchorVote per-vote signature -- a frozen negative pair (FR-VERIFY-004)

Not a `conformance/vectors/` family: those five(+) are the cross-language
(Rust/Python/Go) wire-codec locks (12 §3.4), gated through
`conformance/vectors/EXPECTED` and `tools/ci/conformance_crosslang.sh`. The
per-vote signature is Go-only both ends -- `go/mark1d/internal/anchors`
(producer, `Runner.signVote`) signs, `go/controld/internal/ingest`
(`verifyAnchorVoteSignature`, stage 6) verifies -- so it does not belong to
that gate. This directory is the small, Go-checked equivalent: a frozen
signed-good/tampered pair under `conformance/`, consumed by
`go/controld/internal/ingest/conformance_test.go`.

## Scheme

`AnchorVote.signature` is Ed25519 by the device origin key over the
**deterministic protobuf marshal of the `AnchorVote` message with
`signature` cleared** (`proto.MarshalOptions{Deterministic: true}`) --
verify.proto's `canonical(anchor_id, vote, evidence, integrity)`. No domain
prefix: that's the receipt chain's separate JSON canonicalization
(`conformance/vectors/receipt/`), not this one.

Test-only key: Ed25519 seed `0x11 * 32` (same convention `vectors/receipt/`
already uses for its device key -- reused, not reinvented).

## manifest.json

- `device_pubkey_hex`: the 32-byte Ed25519 public half of the test seed.
- `signed_good_hex`: a fully-populated `AnchorVote` (tool `ruff`, one error),
  deterministic-proto-marshaled, signature included -- verifies under the key
  above.
- `tampered_hex`: the SAME vote with `evidence.counts.errors` bumped 1 -> 2
  **after** signing, so the (unchanged) signature bytes are now stale. This is
  the exact shape ingest's stage 6 must refuse with `M1E-2010`: content
  mutated post-signature, not a corrupted signature field.

Regenerate (if the AnchorVote schema or the fixture's field values ever
change) with the throwaway generator described in the lane's build notes: sign
`canon := proto.MarshalOptions{Deterministic:true}.Marshal(av)` with the seed
above, set `av.Signature`, re-marshal for `signed_good_hex`; clone, mutate
`Counts.Errors`, re-marshal (signature untouched) for `tampered_hex`. There is
no `gen_vectors.py` here -- two vectors, regenerated by the Go test that
already asserts them, is not worth a second generator script.
